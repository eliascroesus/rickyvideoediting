# Ricky Video Editing

Workspace for raw footage, the edit asset library, and finished edits.

| Folder | What goes there |
|---|---|
| [`raw-videos/`](raw-videos/) | **Upload your unedited clips here**. See the [upload guide](raw-videos/README.md) |
| [`edited-videos/`](edited-videos/) | Finished edits |
| [`assets/music/`](assets/music/) | 32 tension / suspense / intense action tracks + stings |
| [`assets/sfx/`](assets/sfx/) | 796 sound effects: risers, booms, braams, whooshes, hits, heartbeats, clocks, glitches, UI pops… |
| [`tools/`](tools/) | Scripts used to build assets |

- What every track and SFX pack is good for: **[assets/README.md](assets/README.md)**
- Licenses & the credit line to paste when you use the music: **[assets/CREDITS.md](assets/CREDITS.md)**

Video files are stored with Git LFS (see `.gitattributes`), so clips up to 2 GB each are fine
when uploaded with GitHub Desktop or git. The website's own uploader stops at 25 MB.
