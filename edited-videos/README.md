# Edited videos

Finished edits land here, usually with the same name as the raw clip plus a suffix
(e.g. `gym-pr-attempt_tiktok.mp4`).

If an edit uses music from [`../assets/music/`](../assets/music/), the matching
credit line is listed next to it. Paste it into your caption / description when posting
(see [`../assets/CREDITS.md`](../assets/CREDITS.md)).
